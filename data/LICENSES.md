# Data and image licenses (Aurum Jewelry demo catalog)

Every file below was created by the GiftFit team for the hackathon. No third-party photo, illustration, font,
logo, product name or trademark is used. YouCam units spent on this catalog: **0** (no text-to-image calls).
Twelve demo-critical SKUs also have an AI-generated photo-real image (ADR-018, section below).

Notes
- "Aurum Jewelry" and all product names (e.g. "Halo Drop Earrings", "Deepwater Diver 42") are invented for the demo.
  A test (`scripts/catalog/__tests__/catalog.test.ts`) rejects a list of real jewelry and watch brand and model names.
- Watch dials carry no text, numerals or logo.
- Style and face-shape tokens follow `lib/contracts/giftfit.ts`, which cites `docs/research/jewelry_rules.md`; the
  catalog only *tags* products with those tokens and quotes no source text.
- Re-create every vector file with `npx tsx scripts/catalog/generate.ts` (deterministic output). The 12 photos are not
  reproducible from code; they are wired into catalog.json by `scripts/catalog/photos.ts`.
