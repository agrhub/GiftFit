About this demo

Lumen & Co. is a fictional shop served from its own origin to show that one script tag adds the GiftFit gift assistant to any store: a floating character, a chat with the Gift Concierge, and a private try-on link for the person you're shopping for.

This page has no product, so the assistant offers general help instead of “Gift this?”.
